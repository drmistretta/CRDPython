# Student Instructions: GitHub Setup & CRDPython Submission Workflow

## Overview

In this course, you will:
1. Create a GitHub account
2. Fork the CRDPython template repository
3. Download and modify the template in Google Colab
4. Submit your work via a **pull request** on GitHub

This document walks you through each step.

---

## PART 1: Create Your GitHub Account

### Step 1: Sign Up for GitHub
1. Go to **https://github.com**
2. Click **Sign up** (top right)
3. Enter your information:
   - Email address (use your school or personal email)
   - Create a strong password
   - Choose a username (e.g., `firstname-lastname` or `firstname101`)
4. Click **Create account**

### Step 2: Verify Your Email
1. GitHub will send you a verification email
2. Click the link in the email to verify your account
3. You may be asked to confirm you're human

### Step 3: Complete Your Profile (Optional)
1. Click your profile icon (top right) → **Your profile**
2. Click **Edit profile**
3. Add:
   - A profile photo
   - Your name
   - A short bio (optional)
4. Click **Save**

✅ **Your GitHub account is now ready!**

---

## PART 2: Fork the CRDPython Repository

A **fork** creates your own personal copy of the template repository. You can modify it without affecting the original.

### Step 1: Navigate to the Template Repository
1. Go to **https://github.com/drmistretta/CRDPython**
2. You should see:
   - The README description
   - The template file: `CRD_Fall_2026_Passion_Project_Template.ipynb`

### Step 2: Fork the Repository
1. Click the **Fork** button (top right of the page)
2. GitHub will ask where to fork it — select your personal account
3. GitHub creates your own copy at: **https://github.com/yourusername/CRDPython**
4. Wait for the fork to complete (usually takes a few seconds)

✅ **You now have your own fork of CRDPython!**

---

## PART 3: Download the Template to Google Colab

### Step 1: Navigate to Your Fork
1. Go to **https://github.com/yourusername/CRDPython** (your fork)
2. You should see the same template file

### Step 2: Open the Template in Google Colab
**Option A: Direct Open in Colab (Recommended)**

1. Click on the template file: `CRD_Fall_2026_Passion_Project_Template.ipynb`
2. Look for the download button (↓) in the file toolbar
3. Click the dropdown next to it → **Open in Colab**
4. Google Colab will open the notebook automatically

**Option B: Manual Upload to Colab**

1. Go to your fork on GitHub
2. Click the template file
3. Click the **Download** button (↓ icon, top right)
4. Save the file to your computer
5. Go to **https://google.colab.research.google.com**
6. Click **File** → **Upload notebook**
7. Select the downloaded file
8. Colab will open the notebook

✅ **The template is now open in Google Colab!**

---

## PART 4: Modify Your Template in Google Colab

### Step 1: Edit Your Notebook
1. Work on the template in Google Colab:
   - Add your own code
   - Fill in any required sections
   - Run cells to test your code
   - Add comments and documentation

### Step 2: Save Your Work to GitHub
Google Colab can save directly to your GitHub fork:

1. In Colab, click **File** → **Save a copy in GitHub**
2. Colab will ask you to authorize GitHub access (first time only)
3. Select your repository: `yourusername/CRDPython`
4. Enter a commit message such as:
   - `Complete passion project template`
   - `Final version of assignment`
5. Click **OK**

Your modified notebook is now saved to your GitHub fork!

**Alternative: Manual Save to GitHub**

If the Colab auto-save doesn't work:
1. In Colab, click **File** → **Download** (.ipynb)
2. Save the file to your computer
3. Go to your fork on GitHub: **https://github.com/yourusername/CRDPython**
4. Click **Add file** → **Upload files**
5. Drag and drop your modified notebook
6. At the bottom, enter a commit message: `Complete passion project`
7. Click **Commit changes**

✅ **Your work is now saved in your GitHub fork!**

---

## PART 5: Submit Your Work via Pull Request

A **pull request** is a formal way to submit your work to your instructor. It allows the instructor to review your changes and approve them.

### Step 1: Open a Pull Request
1. Go to your fork on GitHub: **https://github.com/yourusername/CRDPython**
2. Click the **Pull requests** tab (near the top)
3. Click the green **New pull request** button
4. GitHub will show you a comparison:
   - **base repository:** `drmistretta/CRDPython` (instructor's repository)
   - **head repository:** `yourusername/CRDPython` (your fork)
5. Review the files that will be included in your pull request
6. Click **Create pull request**

### Step 2: Add Your Pull Request Title and Description
1. In the title field, enter:
   - `Submission: Passion Project - [Your Name]`
   - Example: `Submission: Passion Project - John Smith`

2. In the description field, add a brief message such as:
   - `This notebook contains my completed passion project template with all required code and documentation.`
   - `I have completed the assignment and am submitting my work for review.`

3. Click **Create pull request**

✅ **Your pull request has been submitted!**

---

## PART 6: Wait for Instructor Review and Approval

### What Happens Next:
1. Your instructor will receive your pull request
2. They will review your code and work
3. They may:
   - **Approve** your pull request (your work is accepted)
   - **Request changes** (you need to make revisions)
   - **Leave comments** (feedback on your code)

### If Changes Are Requested:
1. You will receive a notification from GitHub
2. Go back to your fork on GitHub
3. Make the requested changes in Google Colab
4. Save your changes to your fork (same process as Part 4)
5. GitHub will automatically update your pull request with the new changes
6. Your instructor will review the changes again

### When Your Pull Request Is Approved:
1. Your instructor may merge your pull request
2. You will receive a notification
3. Your work is now officially submitted and graded

## Common Questions

**Q: What's a fork?**
A: A fork is your own personal copy of the repository. You can modify it freely without affecting the original.

**Q: What's a pull request?**
A: A pull request is a formal request to submit your work. It allows your instructor to review and approve your changes.

**Q: Will my changes affect the original repository?**
A: No. Your fork is completely separate. Only when your instructor approves your pull request will changes be merged.

**Q: Can I make changes after submitting my pull request?**
A: Yes! Any changes you make to your fork will automatically appear in the pull request. Simply make the changes and save them to GitHub.

**Q: Do I need to know Git commands?**
A: No. For this course, you can work entirely in Google Colab and use GitHub's web interface. No command-line knowledge required.

**Q: What if I make a mistake?**
A: No problem! Make the correction, save to your fork, and your pull request will be automatically updated.

## Troubleshooting

| Problem | Solution |
|---------|----------|
| Can't find the Fork button | Make sure you're logged into GitHub. If not, log in and reload the page. |
| "Open in Colab" button doesn't appear | Try downloading the file and uploading it to Colab manually instead. |
| Google Colab won't save to GitHub | Check that you've authorized Colab to access your GitHub account. Try manually uploading instead. |
| Can't find your fork | Go to github.com, click your profile icon (top right), then click "Repositories". |
| Pull request shows no changes | Make sure you saved your changes to your fork on GitHub before creating the pull request. |
| Can't see the Pull requests tab | Make sure you're on your fork, not the original repository. |
